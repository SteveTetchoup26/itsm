# Décisions d'architecture (ADR)

Un ADR (Architecture Decision Record) documente une décision structurante : son contexte,
les options étudiées, le choix fait et ses conséquences. Un ADR n'est jamais supprimé ni
réécrit : si la décision change, un nouvel ADR remplace l'ancien.
