# Journal de bord

Une entrée courte à chaque fin d'incrément (ou après une séance marquante), nommée
`AAAA-MM-JJ-sujet.md`. Elle sert à se souvenir, à préparer les entretiens et à donner
le contexte au mentor en début de session.

## Modèle d'entrée

```markdown
# AAAA-MM-JJ : titre

## Ce qui a été fait
## Ce qui a bien marché
## Ce qui a coincé, et comment je l'ai résolu
## Ce que j'ai appris (avec mes mots)
## Prochaine étape
```
